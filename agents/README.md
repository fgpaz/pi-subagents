# Definiciones de agentes

Este directorio contiene las definiciones de agentes del repositorio. Por ejemplo, existen `worker.md`, `delegate.md` y `reviewer.md`, además de definiciones específicas para proveedores. Consulta cada archivo para conocer sus instrucciones y capacidades declaradas.

Esta página es solo un índice. No define un roster, añade tipos de agente ni establece reglas de lanzamiento o ciclo de vida. La implementación upstream de pi-subagents, su configuración y documentación existentes, y las instrucciones del operador siguen rigiendo el ciclo de vida, la selección y la configuración de agentes.
